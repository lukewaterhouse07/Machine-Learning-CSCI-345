## Getting Started

### 1. Install

You will need:

- Python
- VS Code
- uv
- VS Code **Python** and **Jupyter** extensions

### 2. Clone the Repository

```bash
git clone <REPOSITORY-URL>
cd <REPOSITORY-DIRECTORY>
```

### 3. Create the Environment

```bash
uv venv
```

Activate it:

Windows
```bash
.venv\Scripts\activate
```

macOS/Linux
```bash
source .venv/bin/activate
```
### 4. Install Dependencies
```bash
uv pip install -r requirements.txt
```
### 5. Open in VS Code
```bash
code .
```
Open the lab's `.ipynb` file and select the **`.venv`** Python environment as the notebook kernel.

Run the notebook cells from top to bottom and complete the activities and practice exercises.
